# UI Replacement Plan

## UI Language

- Neon tube highlights over dark metal/vault panels.
- Circular primary spin control with strong gold/teal contrast.
- Compact but readable bottom control bar for desktop.
- Thumb-safe mobile controls with clear spin/bet/menu grouping.
- Clear disabled/loading/reconnect states.

## Required UI Assets

- Spin / stop buttons.
- Bet increase/decrease and bet panel.
- Buy feature button and confirmation panel.
- Menu/settings/help/paytable icons and panels.
- Autoplay and turbo controls.
- Sound/music toggles.
- Balance, bet, win amount typography and bitmap/dynamic font.
