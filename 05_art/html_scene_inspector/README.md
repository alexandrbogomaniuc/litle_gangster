# Little Gangster HTML Scene Inspector

This is a static local inspector for Little Gangster scene maps and v0.3 result-state planning. It makes no external network fetches and must not contain donor URLs, tokens, or executable donor code.

## v0.3 Planning Mode

The inspector includes preview toggles for cascade states, golden-square overlays, rainbow activation, coin reveal tiers, feature modes, max-win cap/win tiers, round completion, and reconnect/state persistence notes.

## Release Boundary

Internal donor/scaffold preview only. Not approved for release. All scaffold assets require replacement or explicit approval.

The client is renderer-only for v0.3 planning: it consumes backend/runtime result payloads and does not generate production RNG, calculate authoritative wins, perform wallet/accounting, or treat registration metadata as an animation schema.
Current GS result owner remains unproven, so full GameClientBuilder remains blocked pending runtime/result API review.
