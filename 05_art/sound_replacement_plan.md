# Sound Replacement Plan

## Direction

Original sound should combine noir jazz, muted brass stabs, city ambience, subtle vault mechanics, coin/cash accents, and responsive UI clicks. It should support fast slot feedback without masking wallet/runtime error sounds.

## Required Original Or Licensed Audio

- Main loop: low-tempo city-heist groove.
- Free-spins loop: higher-tension heist mode with percussion.
- Bonus-buy confirm/cancel stingers.
- Spin, stop, reel/cell settle, symbol pop.
- Cluster win, count-up, big-win tiers.
- Wild/scatter feature hits.
- Error/reconnect understated alert.

## Release Rule

Captured scaffold audio remains `blocked_from_release`; final audio must be original, internally approved, or licensed.
