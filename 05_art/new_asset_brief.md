# New Asset Brief

## Scope

Create a complete original Little Gangster asset package for a 6x5 cluster slot. Use scaffold previews only to understand layout, scale, and scene needs.

## Required Asset Families

- Base city/backroom background and loading/intro background.
- 6x5 grid frame, cells, cluster highlight layer, win markers.
- Symbol set: wild, scatter, four character/prop premium symbols, four letter/low symbols.
- Free-spins `Heist Mode` overlays, counters, intro/outro.
- Bonus-buy `Start the Job` panel and button states.
- Big-win `Vault Break` counter, money burst, tier labels.
- UI buttons: spin, stop, bet +/- controls, buy feature, menu, settings, autoplay, turbo, sound/music.
- Bitmap/dynamic font treatment for win and balance display.
- Original music and SFX package.

## Technical Constraints

- Target layout: 6 columns x 5 rows.
- Must support desktop and mobile safe areas.
- Must expose clean asset names that match object IDs or documented aliases.
- Must include idle/win states for symbols and overlay/effect states for features.
- Every final asset requires ownership evidence before release.
