# Backend Adapter Input Requirements

The future backend adapter must receive an authoritative result generated by the server math owner.

Input contract:

- game id and game key.
- schema version.
- math version.
- RTP variant.
- round id.
- spin id.
- session reference.
- state version and request counter.
- idempotency/client operation references.
- bet context.
- authoritative v0.3 result object.
- cascade steps.
- feature mode state.
- golden-square state.
- rainbow activation events.
- coin reveal events.
- special reveal events.
- bonus-buy state.
- max-win cap state.
- round completion state.
- history and recovery snapshot.
- wallet/accounting references outside game payload.

Forbidden adapter input:

- browser-generated RNG.
- browser-generated authoritative result.
- registration-supplied executable math.
