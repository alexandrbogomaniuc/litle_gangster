# Bonus Buy EV Notes

Bonus buy is represented as a configurable feature but remains blocked pending EV validation.

Candidate cost multipliers are present for smoke simulation: 100x, 125x, and 150x. These are not approved product values. Wallet/accounting for a purchase must remain outside `presentationPayload.gamePayload`; the game payload may describe
purchased feature start state only after the authoritative backend owns the result.
