# Scripted Visual Outcomes

Scripted outcomes exist only to review presentation timing. They are not generated by
real math, wallet, GS, RTP, or certification systems.

Recommended sample scenarios:

- loading
- base no-win
- base small win
- cascade win
- free-spin trigger
- free-spin mode sample
- bonus-buy entry sample
- big-win placeholder
- max-win placeholder
- history/replay placeholder
- wallet/error placeholder

Use placeholders for unresolved values such as `{BF_BETS_PENDING}`,
`{MAX_WIN_PENDING}`, `{BF_RTP_PENDING}`, `{SD_KEY_PENDING}`, and
`{NON_EUR_EXPOSURE_PENDING}`.
