# Certification Evidence Package

ParallelMathValidator may assemble evidence for certification review, but it
does not certify math or approve release.

## Package Contents

- Game key and math version.
- Rules version.
- RTP/volatility profile matrix.
- Seed policy and proof validation seeds were not used for tuning.
- Train results.
- Validation results.
- Tail/max-win results.
- Bonus-buy results if applicable.
- FRB/promo liability results if applicable.
- Jackpot results if applicable.
- Registration math field extraction.
- Confidence limits and unresolved blockers.
- Exact values final: false unless a separate final gate approves.
- Certification status: false unless a separate final gate approves.

## Forbidden Claims

Do not claim certified, release-ready, or lab-approved from parallel evidence
alone.
