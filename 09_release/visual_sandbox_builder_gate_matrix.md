# Visual Sandbox Builder Gate Matrix

| Gate | Status | Meaning |
|---|---|---|
| Visual sandbox allowed | true | Internal sandbox work is allowed only under `11_prototypes` and only as non-production review. |
| Donor/reference assets | placeholder only | Assets are quarantined, non-production, blocked from release, and replacement-required. |
| Scripted visual outcomes | visual only | Outcomes are not math, RTP, feature-odds, wallet, registration, release, or certification evidence. |
| GameClientBuilder implementation | false | Sandbox output does not unlock production client implementation. |
| Registration generation | false | Sandbox output does not unlock registration generation. |
| Wallet endpoint tests | false | Sandbox output does not unlock wallet endpoint tests. |
| Public export | false | Donor/reference sandbox assets and scripts must not leak into public export. |
| Release/certification | false | Sandbox output is not release or certification evidence. |
