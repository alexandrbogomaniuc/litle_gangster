# Checkpoint Git Review Policy

Every 3-4 local sprints, run a checkpoint review/push sprint.

Policy:

- Checkpoint push is not required every sprint.
- Push only after raw GitHub validation passes.
- Do not rely only on agent reports.
- Use pushed artifact validation as truth.
- Validate working tree, git blob, and pushed/raw artifacts when public export is involved.
- If raw pushed artifacts contradict local reports, treat pushed artifacts as source of truth and block release claims.

This policy does not run public export or push in this sprint.
