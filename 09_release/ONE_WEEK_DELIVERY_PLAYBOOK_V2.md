# One-Week Delivery Playbook V2

Status: fast-lane delivery template.

## Day 0: Setup And Gates

- Confirm roots, donor authorization, secret policy, game ID, RTP targets, and checkpoint state.
- Create/update manifest and handoffs.

## Day 1: Reference And Assets

- Run donor/reference research only when authorized.
- Inventory assets and quarantine unknown/protected materials.
- Do not approve release assets automatically.

## Day 2: Protocol And Math Config

- Lock runtime lane assumptions.
- Define authoritative math owner, RTP models, GL settings, state/history requirements.
- Use handoffs and existing templates instead of repeated full audits.

## Day 3: Fixtures And Scene Contract

- Build strict fixtures and state/scene mapping.
- Validate schema and replay payload shape.

## Day 4: Approved Source Patch Or Stay Blocked

- Apply backend/runtime/schema patch only with explicit user approval.
- Include preflight, tests, rollback, and compact summary.

## Day 5: Client/Registration Gate

- Client implementation only if runtime, result API, assets, and user approval are proven.
- Registration generation only if lane, serializer, math/config, and rollback are proven.

## Buffer: QA, Wallet, Release, Checkpoint

- Run wallet/history/reconnect tests only in approved safe environment.
- Run checkpoint push every 3-4 meaningful local sprints or major phase boundary.

## Compression Principle

Compress repeated planning and report volume, not safety gates.
