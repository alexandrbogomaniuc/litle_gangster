# Public Export Notice

This is a raw-safe sanitized public review checkpoint.

It is not a release build and it is not certification evidence.

Excluded from this export:

- Donor/scaffold asset bodies.
- Screenshots, HAR files, raw logs, and captured media.
- Raw secrets, passwords, SIDs, signatures, tokenized URLs, and private URLs.
- Private local paths and Staging source code.
- Production client implementation, registration artifacts, DB changes, wallet
  calls, GS endpoint calls, BO/CM endpoint calls, and release approval.

Included content is limited to public-safe workflow docs, planning reports,
checkpoint reports, and curated reusable skill snapshots.
